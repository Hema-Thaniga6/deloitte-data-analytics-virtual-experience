# Deloitte Australia Data Analytics Virtual Experience Program (Forage)

## Overview

Completed Deloitte Australia's Data Analytics Virtual Experience Program on Forage, applying data analysis and visualization techniques to solve business problems using Tableau and Excel.

**Tools Used:** Tableau, Microsoft Excel, Data Visualization, Business Analytics

---

## Project 1: Telemetry Data Analysis

### Objective
Analyze machine telemetry data to identify factories with the highest downtime and determine the devices contributing most to operational issues.

### Key Tasks
- Imported and analyzed telemetry data in Tableau.
- Created a calculated field to measure downtime from unhealthy machine statuses.
- Built interactive dashboards showing:
  - Downtime by Factory
  - Downtime by Device Type
- Used dashboard filters to perform root cause analysis.

### Key Insights
- **Daikibo Factory Seiko** recorded the highest downtime (**480 minutes**).
- **Daikibo Shenzhen** recorded the second-highest downtime (**420 minutes**).
- **LaserWelder** machines were responsible for the majority of downtime at Factory Seiko.
- Recommended prioritizing LaserWelder maintenance to reduce operational disruptions.

## Project 2: Forensic Technology Analysis

### Objective
Investigate employee compensation equality data and classify records based on fairness scores.

### Key Tasks
- Added an **Equality Class** column in Excel.
- Classified records as:
  - Fair
  - Unfair
  - Highly Discriminative
- Applied logical formulas to automate classification.

### Key Insights
- Identified records with significant compensation disparities.
- Highlighted highly discriminative cases requiring further investigation.
- Demonstrated how data analytics can support fairness and compliance reviews.
